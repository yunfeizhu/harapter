# Harapter Agent Note Authoring Guide

Follow the repository-wide [Agent Guide](../../AGENTS.md) and the complete
[Agent Note standard](README.md).

- Search active notes and design documents before creating a record. One
  decision has one current owner.
- Use the lifecycle and class encoded in the path; keep status, section set, and
  verb tense consistent with that lifecycle.
- Record genuine alternatives, consequences, evidence requirements, and
  capability given up. Do not invent alternatives to satisfy the template.
- Implemented notes describe current reality and stay synchronized with renamed
  paths or mechanisms without rewriting the decision's rationale.
- Rejected notes remain only while their verdict prevents a plausible mistake.
- Archived notes are frozen historical evidence and never current authority.
- Use [`$harapter-agent-notes`](../skills/harapter-agent-notes/SKILL.md) for
  note creation, transition, rejection, or archival, then run `pnpm check`.
